## 📋 Topics Covered

### Part A: Descriptive & Conceptual Questions
1. Primary Key vs. Unique Key vs. Foreign Key
2. SQL Constraints (`NOT NULL`, `CHECK`, `DEFAULT`, `UNIQUE`, `PRIMARY KEY`)
3. Table Modification: `DELETE` vs. `TRUNCATE` vs. `DROP`
4. Aggregate Functions (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`)
5. Filtering Result Sets: `WHERE` vs. `HAVING` Clauses
6. Relational Table Operations: Inner, Left, Right, and Full Joins
7. Subqueries (Advantages, Disadvantages, and Correlated Subqueries)
8. User Defined Functions (UDFs) & Types
9. Stored Procedures vs. Functions
10. Database Normalization (1NF, 2NF, 3NF)

### Part B: Hard-Level Practical Queries & Solutions
1. **Finding the Second Highest Salary** using advanced subqueries / window functions.
2. **Conditional Bonus Calculator Function** using custom UDF logic (`DELIMITER`, `IF-ELSE`).
3. **Relational Maximum Fee Analysis** connecting students and courses.
4. **Sales Analytics with CTEs** filtering categories above overall average sales.
5. **Performance Grading & Grouping Engine** evaluating student scores and ranking max density groups.
